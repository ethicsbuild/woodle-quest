# On Purpose, the reading room

words.woodle.quest: Gage Cass Woodle's own-name Substack pieces on a plain page.
No account, no app, no comments, no trackers, nothing loaded from Substack.

How it runs: every hour a GitHub Action reads the Substack feed, cleans each piece,
saves it to `posts/` (images to `images/`), and republishes the site.
Saved pieces stay even after they age out of the feed.

Own-name work only. Nothing from any other byline belongs here.
